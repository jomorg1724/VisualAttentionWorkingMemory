# Implemented sensory battery: declared numerical adaptations

The user authorized the recommended seven-task battery. This document records the actual version-3 controlled task parameters in `neuroscience_stimuli.py`; primary-source motivation and methodological limits are in [two_frame_task_research.md](two_frame_task_research.md), [cardinal_motion.md](cardinal_motion.md) and [natural_image_task.md](natural_image_task.md). Values below are raster engineering choices, not measured human thresholds. All trials contain exactly two separate100×100 RGB images.

Each task has an ordered label. Motion has four classes, in order right/up/left/down. Orientation label0 means second orientation is counterclockwise and label1 clockwise; positive angles rotate clockwise in image coordinates where y increases downward. For the remaining tasks label0 identifies frame0 and label1 frame1 with the higher quantity or aligned contour. Labels are exactly balanced for even binary batches and multiples-of-four motion batches. Each displayed difficulty level is sampled with equal probability; there is no staged curriculum.

| Task | Actual randomized signal levels | Shared / independent nuisance |

| Motion direction | Displacement1,2,3pixels; coherence1 among surviving dots | 256 periodic-domain dots,128 survive128 reborn, same aperture; unchanged from version2 |

Orientation, contrast and spatial-frequency gratings have a Gaussian envelope with sigma19pixels at the image center. A sinusoid is multiplied by the envelope, its residual discrete mean is subtracted and its peak absolute value is scaled to1 before multiplying by the numerical amplitude c. The actual displayed mean is0.5, with independent uniform per-pixel noise between−0.004and0.004, identically distributed for both intervals. **Code metadata named contrast/pedestal/increment denotes signed intensity modulation amplitude**, not calibrated Michelson contrast: with symmetric extrema around0.5 the Michelson value would be2c. Finite windowing makes extrema slightly asymmetric. The contrast task uses one shared grating pattern, so its peak normalization does not erase the amplitude increment. Grayscale values are repeated across all three channels. Inputs are checked to remain in gamut; grating signals are not clipped or independently RMS-normalized after amplitude is applied.

The chromatic axis is the unit vector proportional to `(0.7152,−0.2126,0)` in declared linear RGB. Its dot product with luminance weights `(0.2126,0.7152,0.0722)` is zero. The increment therefore preserves that numerical luminance to floating-point precision before independently drawn uniform sensor noise of±0.001 per channel. Both patches share geometry with a one-pixel soft border; no gamma transform or gamut clipping occurs. This is not observer-calibrated isoluminance or a cone-isolating stimulus.

For contour trials, a seven-element path is sampled from `(31t,b*t²)` for seven equally spaced t in[−1,1], with bend b uniform[−9,9]pixels. It is randomly rotated and slightly translated around center. Clutter is placed with minimum continuous-center spacing10pixels, then positions round to integer pixel centers. All32elements use sigma2pixel Gaussian envelopes on11×11supports, wavelength5pixels and contrast0.34. Structured path carriers are normal to path tangents plus the chosen jitter. The comparison permutes the same orientation multiset among the same element positions, while each position retains its phase. Background elements can accidentally align and controls can retain partial contours; the target is the generating condition, not a claim that every control is perceptually contour-free. Rotation, clutter spacing and element statistics are shared, so density differences cannot mark the target.

All task metadata are audit outputs only. `state_dict` stores local RNG, counter, protocol version and natural dataset identity when opened; restoration rejects a mismatched protocol or source identity. Procedural examples remain fresh, and actual train/validation/test seeds are set and recorded by the benchmark runtime. No latent task parameters enter the encoder or decoder.

Focused CPU evidence is in `sensory_battery_check.json`: correct tensor shape/range, balanced labels and exact stream replay for each controlled task; simple image-domain checks recover orientation sign, higher contrast, higher frequency and chromatic increment on24trials each; swapping the contour target interval exactly swaps the generated pair under restored RNG. Those checks establish task signals and label consistency, not learned encoder performance or biological validity.
