# Learn retention with the existing E/I dynamics

This experiment continues the selected ReadoutRefit step9840 checkpoint. The question is whether its existing recurrent dynamics can learn to retain a motion-duration decision versus a one-item orientation feature over longer blank intervals. No attention, new recurrent state, object set, distractor, longer evidence sequence or cloud run is introduced.

Motion presents the existing eight-transition dot movie, then D inserted blank frames, then report: T=11+D, final-evidence-to-report age D+1 updates. Orientation retains the existing instruction and two sample rasters, D blanks, one query cue and the comparison probe carrying the report cue: T=5+D, final-sample-to-probe age D+2. The existing `post_delay` parameter is query-to-probe waiting; it is fixed at0. Blank frames carry the established ignore-phase glyph. Primary D values are0,4,12,24 for both tasks; these are model updates, not calibrated biological milliseconds.

The standard renderer/cues/labels remain unchanged. Evaluation restores the complete sampler state across delays and checks exact evidence, sample, query, probe and label equality after removing inserted blanks. Ordinary blank generation consumes no RNG. Each primary family therefore has512 fresh test evidence groups shown at four delays, not2048 independent groups. Anchors add512 independent two-frame examples per family. Baseline and selected trained weights see the same final test movies.
