# Frozen E/I state accessibility

Question: does early directional evidence remain accessible at the final report, and can a new diagnostic readout improve duration decisions using the existing output-accessible state?

The selected E/I step5000 checkpoint is frozen. Training data here fit diagnostic probes only; no original encoder, recurrence, adaptation, projection or head parameter is updated. New local1200-second cap includes extraction, fitting, evaluation and reporting. The supervisor allows1140seconds for its exact child, reserving60seconds for receipts; the child stops at1120seconds if unfinished.

We pin3072 probe-training,768 validation and1024 held-out movies at the trained eight-transition length. Canonical schedules begin with direction0; cyclic rotations are equivalent for split assignment. All unique-winner canonical schedules are randomly partitioned70/15/15 before selecting pairs within a split. Each pair has the same last two directions, different duration winners and different first-four-transition count vectors. No individual canonical schedule or its rotations appears across splits. Each selected pair is rendered at all four rotations with independent render seeds, giving384/96/128 canonical pair templates respectively. Partners use restored full stream RNG; identical instruction, final two evidence rasters and report are checked exactly. All movies remain physically continuous.

The regression target is the first four transition counts of right/up/left minus1 each; down is determined by the sum4 constraint. The prefix state is captured after transition4, image index5 (instruction0, initial dots1). Final state follows the report at index10. Linear ridge models use prefix r, prefix[r,a], final r, final[r,a], sensory128, or sensory128+r256. The sensory feature retains opponent-trace history and is not a current-frame-only control. Adaptation a is diagnostic-only: the ordinary output receives r, so neither duration probe reads a.

Each ridge uses training-only per-feature standardization, an unpenalized target-mean intercept, and lambda from{0.0001,0.01,1} multiplying squared weight norm in a mean-squared-error objective. Validation MSE selects lambda. Six count regressions and one duration ridge yield21 fitted ridge candidates. Duration ridge targets four one-hot classes; its raw scores are not calibrated probabilities.

One modest nonlinear architecture is reused: input→64 SiLU→output, Adam0.001, weight decay0.0001, batch256,150 epochs, validation every10epochs. Minimum validation MSE selects prefix[r,a]/final[r,a] count regressors; minimum validation cross-entropy selects the sensory+r duration classifier. These are three target/feature fits of one fixed architecture, not a capacity sweep. Scalers fit training only. Probe selection is saved before held-out feature collection/scoring begins. Existing model outputs are evaluated on the same held-out movies. A single first-batch equality check verifies the explicit stepwise extractor reproduces existing model.forward logits exactly.

For count recovery, ordinary held-out R² and within-pair count-difference R² are reported. The latter compares predicted pair differences with true count differences and removes all pair-common suffix cues; a constant/common-suffix-only prediction has zero difference. Probe failure does not prove information erasure. Duration BA equals accuracy because rotations balance every class; confusion matrices and macro classwise OVR ranking AUC are retained. Ranking uses each method's raw class score (original/MLP logits or ridge scores), not a claim of probability calibration.

Uncertainty for duration decisions resamples128 held-out canonical pair-template clusters1000times, keeping both partners and all rotations together. Repeated variants, classes and probe methods are not independent examples. This intentionally controlled schedule distribution differs from the earlier random test distribution and from the separate recency bank. The test contains new movie templates/render seeds but only one trained E/I checkpoint.
