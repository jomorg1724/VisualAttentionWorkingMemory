# Spatial comparison stimuli

`SpatialStream(seed, split)` provides independent, checkpointable streams for `orientation_single`, `orientation_binding`, and `motion_direction`. `batch(n, family, condition)` returns CPU float32 images `[B,T,3,100,100]`, int64 labels, and analysis-only metadata. Conditions accept a dictionary (`delay`, optional `spacing`), an integer delay, or a name containing `D0`, `D4`, `D12`, or `D24`. Model heads map to `orientation`, `orientation_binding`, and `motion_direction` respectively. Only image tensors should enter the model. `state_dict` / `load_state_dict` include RNG, counters, and unfinished four-case blocks.

Single-item orientation directly reuses `SequenceStream` recall with load 1 and query-to-probe `post_delay=0`. Motion directly reuses eight-transition duration integration. Binding is the only new task. Its timeline is an instruction, two simultaneous-pair sample frames, D blank frames, a neutral query glyph, and a simultaneous-pair probe/report: T=5+D. Motion has T=11+D. All glyphs use existing `visual_cues`; neither label nor item assignment changes a glyph.

Binding asks whether the two orientations stayed at their original locations (label 0) or exchanged positions (label 1). Every episode keeps the same unordered orientation inventory at sample and probe. The four cases sample A/B or B/A × preserve or swap occur once in every shuffled four-episode block. Consequently each location's sample and probe item assignments have exactly balanced categorical marginals across labels. Base angle is uniform on the axial interval [0,π); signed separation is uniformly selected from ±15°, ±30°, ±60°. Nuisances and base angles are freshly drawn per episode: raster marginals match across labels in distribution, rather than through duplicated rendered episodes. Each episode is an independent nuisance/evidence draw, with the disclosed four-case assignment balancing dependence.

The two patches share an episode-level wavelength (uniform 5–7 pixels) and amplitude (uniform 0.26–0.34), so those properties cannot identify an item or travel with a swap. Each patch receives a new independent phase on every sample and probe frame; each frame receives independent Gaussian pixel noise (SD 0.008). A circularly truncated Gaussian envelope has sigma 4.5 pixels and radius 11 pixels. Orientation is the carrier-axis angle. The display stays achromatic and is clipped to [0,1]. Phase independence prevents exact pixel matching from solving preserved trials; this remains an image comparison task with spatial cues, not a neuroscientific claim about binding mechanisms.

Both near (26-pixel center spacing) and far (46-pixel spacing) appear in training. Standard train/validation/test locations use pair midpoint x ∈ {46,50,54}, common y ∈ {32,50,68}. The separate `locations` split uses midpoint x ∈ {48,52}, y ∈ {41,59}. These finite held-out centers are disjoint from every standard center, while preserving spacing, appearance, and timing. All supports avoid the 10-pixel cue borders and never overlap. The location split tests interpolation to unseen grid centers, not extrapolation beyond the trained region. Spacing and separation strata are random and should be reported with actual cell counts.

Blank generation consumes no random numbers. Restoring the full stream before changing D gives identical instruction, sample, query, probe, and labels across delays; those repeated presentations share an episode identity and must not be counted as independent evidence. Native orientation and motion follow their existing renderer semantics. No new visual family or latent state is supplied to a model through this wrapper.

Run the focused CPU checks with `C:/Python310/python.exe -X utf8 -B -m WorkingMemory.SpatialComparison.check_stimuli` from the repository root. `stimulus_checks.json` records shape/range, full-state replay, exact cross-delay evidence, task-local RNG independence, algebraic balancing, phase independence, and location geometry checks. `stimulus_contact_sheet.png` shows sample/probe examples for preserve/swap and near/far spacing.
