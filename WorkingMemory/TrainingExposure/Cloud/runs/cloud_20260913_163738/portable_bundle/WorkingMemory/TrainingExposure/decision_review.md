Reviewed `model.py`, `protocol.py`, `worker.py`, `sweep.py`, `check.py`, saved `checks.json` and `README.md`. No substantive issue prevents the authorized Stage 1 run. No additional tests or review cycle is required.

The architecture is exactly the trained attention8400 model. Migration restores its complete model and optimizer state without added parameters. The saved CPU checks compare all optimizer groups and tensors and establish that the control recipe equals the parent's recipe. Runtime restores full parent family-local streams, Python/NumPy/Torch/CUDA RNG, global step and counters; resumed checkpoints restore counters without double addition. Existing losses, cues, labels, task heads, learning rates, clipping, decay and full BPTT remain intact.

Only the 80-update allocation changes: control uses nine updates per orientation/binding cell and four per motion cell; focused uses five and twenty respectively. Both receive 4,000 additional updates at batch eight. This matches total episodes and updates, not physical frame exposure or delay-specific evidence prefixes. The inherited family-local sampler provides shared evidence prefixes within each family, and the README correctly discloses that schedules may associate those episodes with different delays.

Selection uses only the paired validation set. It first screens all ten trained cells for no greater than two percentage points BA loss versus frozen parent, then ranks eligible candidates by minimum motion BA and mean motion AUC. The strict improvement comparison preserves earlier ties; including the parent gives the intended fallback. This empirical screen is not a statistical equivalence guarantee. All five planned training blocks continue regardless of eligibility. Fresh test evaluation retains parent, selected and terminal outputs, reusing identical evaluations when these refer to the same checkpoint; rejected terminal behavior is not hidden.

The same worker/protocol is used for both placements. Disposable profiling does not seed production. Fixed 4,000-update exposure must fit the measured estimate and evaluation reserve; otherwise execution stops rather than silently producing an unequal reduced arm. Local time is bounded by its new 14,400-second ledger and cloud time by the external creation-based deadline. Both supervisor and worker enforce the deadline. Cloud packaging, retrieval and deletion remain the assigned researcher's responsibility.

Interpret this as an allocation-policy comparison with a matched trained starting point, not a pure motion-example-count intervention: nonmotion exposure, temporal ordering and delay assignments also change. Final reporting should retain paired ten-cell preservation analysis, binding block dependence, physical frame counts, and GPU/platform differences. No superiority or preservation result is established by this pre-run review.
