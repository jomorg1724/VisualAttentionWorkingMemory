# Attention without explicit source and distance priors

The old-task arm removes only `attention.source_bias` and `attention.raw_locality` plus its distance buffer from the trained attention8400 parent. It retains trained query/key/value/output projections, their interface normalization, and learned position/source embeddings. Thus learned content can still prefer either source or local positions. No query/key reset, new state, phase mask, cue oracle or sensory-to-memory bypass is added.

For two heads of width32, memory queries attend jointly to169 sensory and169 memory tokens using `softmax(Q K^T / sqrt(32)) V`. The result remains the sole external drive into the existing spatial E/I memory. Original sensory/comparator decision branches are unchanged. Removing six scalar parameters leaves556,122 parameters. All121 compatible Adam states are copied by parameter name.

The old-task comparison adds exactly4,000 updates of eight episodes with the inherited10% motion80-update schedule, streams, RNG and constant learning-rate policy. Validation at+800/+1600/+2400/+3200/+4000 uses seed53973001 and128 examples/cell; final seed54973001 uses512/cell, including held-out binding locations. These evaluation seeds were previously used by TrainingExposure; interpretation is exploratory. The saved equally exposed biased control is the comparison arm. Validation requires no more than2percentage-point BA loss in any of ten trained cells against the untouched biased8400 parent, then ranks by minimum motion BA and mean motion AUC. Parent fallback is explicitly labeled; terminal unbiased results always remain visible.

The separate spatial battery uses the same inherited unbiased core and five newly initialized128-to-class linear heads, adding1,548 parameters. A step averages five batch8 mean losses, performs full BPTT for each homogeneous-length microbatch, clips the accumulated gradient once at1, and performs one Adam step. Each task therefore has equal loss weight. New heads use3e-4; existing learning-rate groups remain3e-4 or3e-5. No cosine schedule or calibration is introduced. New train/scheduler/validation/test seeds are61973001/62973001/63973001/64973001. See SpatialTaskBattery/PROTOCOL.md for all27 conditions and selection. This is new-task acquisition, not a paired architecture comparison against the old battery.

One48GB cloud GPU runs the two arms sequentially under the original eight-hour pod deadline. Profiles are discarded. Old exposure remains32,000 episodes; spatial target is160,000 episodes, reduced in complete200-update increments before production only if measured cost requires it. The supervisor preserves the original deadline across resume, validates source/checkpoint hashes, and resumes from the latest indexed checkpoint. Uncheckpointed interrupted steps may be replayed from saved RNG/streams and are not new unique exposure. Neither early chance scores nor validation regressions stop training.

Training is fp32 with TF32 disabled, full sequence gradients and the inherited activation checkpoint policy. Checkpoints, predictions, per-condition class confusions, training gradients and per-head attention summaries are retained. The retrieval watcher verifies the archive and every indexed artifact.
