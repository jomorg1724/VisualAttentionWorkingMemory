# Weighted raw-frame RViT cloud attempt

One fresh whole CNN/RViT model, 7,269,426 learned parameters in 92 tensors. No VAE weights or state are used. The existing single-stimulus task retains B12/B20/B28, native 29/37/45-frame movies and fixed causal raw RGB weights 0.5/0.4/0.1. It has no cue or distractor. Adam 1e-4, batch32/micro4, FP32 throughout, full BPTT, no clipping or TF32.

Parent runs provider/SSH actions. A fresh single A40 must cost at most $0.49/hour; no other cloud pod may run. Eight hours of compute plus an explicit $1 storage/retrieval reserve totals at most $4.92. Cap starts before creation; model work ends 600 seconds before the hard deadline. The target is 2,310 updates, 70,000 replay presentations of 7,000 unique movies; measured native profiling may pin fewer complete 330-update pools before production.

Only `best.pt` and `latest.pt` are written. No initial, numbered, profile or terminal checkpoint copies. The detached launchd mirror saves metadata/logs continuously and overwrites its own latest checkpoint when needed. Startup requires persisted update-3 evidence for all 92 named Adam states, fresh initialization and a downloaded CPU reload. Completed retrieval verifies every artifact digest and CPU reloads best/latest before acknowledging the independent guard. Guard stops on completion, failure or deadline even if the laptop disconnects. Cleanup deletes only this attempt after complete local verification and an exact stopped-pod readback. Incomplete retrieval retains stopped storage; it never restarts GPU compute.

Build: `python -m SecondPass.WeightedMeanRViT.bundle --output SecondPass/WeightedMeanRViT/CloudRuntime/package`, then `python SecondPass/WeightedMeanRViT/CloudRuntime/freeze_runtime.py`. Parent deploys with `python SecondPass/WeightedMeanRViT/CloudRuntime/deploy.py deploy --use-existing-guard-credential --storage-reserve-usd 1 --retention-hours 24`. `check` is offline; `inspect` reads provider quote/lifecycle; `status` and `retrieve` never provision or restart.
