6.1 Memory determines how the next frame is selected

Flatten the previous spatial field into vectors \(h_{t-1,i}\). The current visual token and previous memory are normalized separately across their 64 channels. One learned key projection acts on their sum. The query is generated from the previous CLS state plus a learned constant token \(c_*\):

\[k_{t,i}=W_K\left[\operatorname{LN}_V(V_{t,i})+\operatorname{LN}_H(h_{t-1,i})\right],\qquad q_t=W_Q\operatorname{LN}_Q(c_{t-1}+c_*).\]
Symbols and meaning. \(h_{t-1,i}\) is the 64-entry vector stored at location i in the previous spatial field H. LN with different subscripts denotes different learned normalization layers. \(W_K\) produces a key k describing that site; \(W_Q\) produces the single query q from previous global memory c and the learned constant \(c_*\). Both are 64-entry vectors. The query is shared across locations, while keys differ by location.

The query and key projections have no bias. Define \(\mathcal N_\varepsilon(x)=x/\max(\|x\|_2,\varepsilon)\), with \(\varepsilon=10^{-6}\). Normalize the projected vectors and form a scaled similarity:

\[s=1+15\sigma(\kappa),\quad \ell_{t,i}=s\,\mathcal N_\varepsilon(q_t)^\mathsf T\mathcal N_\varepsilon(k_{t,i}),\quad \alpha_{t,i}=\frac{e^{\ell_{t,i}}}{\sum_{j=1}^{100}e^{\ell_{t,j}}}.\]
Symbols and meaning. \(\kappa\) is a learned scalar controlling similarity scale s; sigmoid keeps s between 1 and 16. \(\mathcal N_\varepsilon\) divides a vector by its length with a small denominator floor. The dot product then measures directional alignment. \(\ell_{t,i}\) is the unnormalized attention score, called a logit; \(\alpha_{t,i}\) is its softmax weight. The denominator sums all spatial sites, so the 100 weights total one. This italic logit symbol is distinct from the lag label used in the correspondence chapter.

The learned scale initializes at 8 and remains between 1 and 16. Without an intervention, each logit lies in [−16,16]. Cosine normalization prevents a larger query/key norm from being the sole reason for sharper selection. Large differences between the bounded logits can still concentrate nearly all priority at a few sites. Transformers supplied a general framework for content-dependent weighting; here that operation has been specialized to recurrent spatial selection. [[vaswani2017]] [[dosovitskiy2021]]

The normalized query depends on the previous global state, while keys depend on both current evidence and previous local memory. Thus identical pixels can receive different weights after different trial histories. There is no external instruction telling the attention mechanism which location is the target. Any cue interpretation must be learned from visible pixels and preserved in recurrent state.

6.2 One spatial distribution selects several kinds of evidence

Construct value vectors from the unnormalized visual token and previous spatial state, then add a channel-wise residual feedforward transformation:

\[u_{t,i}=W_VV_{t,i}+b_V+W_Hh_{t-1,i},\quad v_{t,i}=u_{t,i}+W_2\operatorname{GELU}(W_1\operatorname{LN}_F(u_{t,i})+b_1)+b_2.\]
Symbols and meaning. \(W_V,W_H,W_1,W_2\) are learned channel-mixing matrices; b labels their learned biases. \(u\) combines current visual and previous memory information. \(v\) adds a nonlinear residual to u. The inner transformation expands 64 channels to 256; the outer one returns to 64. There is no spatial pooling in this equation.

The feedforward width is 256, returning to 64. It mixes channels at each location. The same \(\alpha\) then selects value vectors and the wider motion-comparison representation:

\[z_t=\sum_i\alpha_{t,i}v_{t,i},\qquad b_t^{\rm selected}=\sum_i\alpha_{t,i}b_{t,i},\qquad m_t=0.8m_{t-1}+0.2b_t^{\rm selected}.\]
Symbols and meaning. \(z_t\) is the selected 64-entry value summary. \(b_t^{\rm selected}\) is the selected 735-entry local comparison. Both use exactly the same attention weights. \(m_t\) stores a running comparison trace: retain 80% of its previous value and add 20% of the current selected comparison. “Selected” labels the pooled vector.

The comparison trace has a fixed decay. An isolated selected comparison retains a fraction \(0.8^k\) after \(k\) subsequent zero-input updates, with a half-life of approximately 3.11 updates. This half-life describes the direct retention in the comparison trace. The CLS and spatial states can have different effective time scales. A blank final frame is still an update and can attenuate the comparison trace.

The common-map hypothesis is implemented structurally: appearance-derived and motion-derived channels enter values selected by one distribution, and explicit motion comparisons are selected by the same distribution.

6.3 A bounded gate controls spatial memory writes

The spatial recurrent unit receives the full value field, with attention controlling its write modulation. Attention instead modulates the effective write fraction:

\[g_{t,i}=\frac{\alpha_{t,i}}{\alpha_{t,i}+1/N},\qquad N=100.\]
Symbols and meaning. \(g_{t,i}\) is one scalar write multiplier per spatial site, shared across its channels. It converts attention mass \(\alpha_{t,i}\) to a bounded write factor relative to uniform mass 1/N. For N=100 and alpha=0.01, g=0.01/0.02=0.5. It is distinct from the global training-gradient vector written in bold later.

At uniform attention \(\alpha=1/N\), \(g=1/2\). At the limiting maximum \(\alpha=1\), \(g=100/101\). Near zero attention, memory replacement is strongly suppressed. This saturating transformation is a deliberate engineering choice: it changes the rate at which a location's state can be overwritten without multiplying the entire recurrent input by a large gain.

A useful connection is to gain control and competition in neural systems. However, channel-wise LayerNorm, cosine normalization, softmax competition, and this saturating write fraction are four distinct operations. Classical normalization models motivate controlling response scale; the implemented operations have their own equations and assumptions. [[heeger1992]] [[carandini2012]] [[reynolds2009]]

6.4 What exactly is normalized?

For a 64-channel vector \(a\) at one patch, layer normalization is

\[\mu(a)=\frac1D\sum_{j=1}^Da_j,\quad \nu(a)=\frac1D\sum_{j=1}^D(a_j-\mu)^2,\quad \operatorname{LN}(a)_j=\gamma_j\frac{a_j-\mu}{\sqrt{\nu+10^{-5}}}+\beta_j.\]
Symbols and meaning. a is the vector being normalized, j indexes its 64 channels, and D=64. \(\mu\) is its channel mean and \(\nu\) its channel variance using divisor D. \(\gamma_j\) and \(\beta_j\) are learned scale and offset for channel j. Subtract the mean, divide by the stabilized standard deviation, then apply those learned affine parameters.

The learned \(\gamma\) and \(\beta\) allow normalized signals to recover useful scale and offset. In the spatial GRU the tensor is rearranged so each patch is normalized across channels independently. Each site, example, and observation uses its own channel statistics. The write gate, reset gate, and candidate each have their own normalization parameters. Layer normalization was developed partly to improve recurrent-state dynamics. [[ba2016]]

GroupNorm generally computes statistics across channels within a group and across spatial positions. BatchNorm would additionally couple examples through training statistics. The chosen normalization keeps a patch's gate statistics independent of other examples and avoids repeatedly forcing the stored memory field itself to unit variance. [[wu2018]]

6.5 Spatial GRU: a patch-based recurrent network

Here \(V_t^{\rm value}\) means the 100 vectors \(v_{t,i}\) reshaped into a 64 × 10 × 10 field. Concatenate current values \(V_t^{\rm value}\) and previous spatial memory \(H_{t-1}\) along channels. A padded 3 × 3 convolution maps 128 input channels to 128 outputs, split into write and reset preactivations. A second 3 × 3 convolution computes the candidate:

\[a^w_t,a^r_t=K_g*[V_t^{\rm value};H_{t-1}]+b_g,\quad w_t=\sigma(\operatorname{LN}_w(a^w_t)),\quad r_t=\sigma(\operatorname{LN}_r(a^r_t)),\]
Symbols and meaning. \(K_g\) and \(b_g\) are a learned spatial convolution and bias. The two halves of its output are \(a^w\), the write preactivation, and \(a^r\), the reset preactivation. Separate LayerNorms and sigmoids convert them to channelwise fractions w and r. Superscripts w and r identify the write and reset gates. The reset r here is distinct from correspondence reliability in the previous chapter.
\[\widetilde H_t=\tanh\!\left(\operatorname{LN}_h\left(K_h*[V_t^{\rm value};r_t\odot H_{t-1}]+b_h\right)\right),\qquad \bar w_{t,i,j}=g_{t,i}w_{t,i,j},\]
Symbols and meaning. \(K_h,b_h\) create a candidate memory field from current values and reset-filtered old memory. The circle-dot multiplies corresponding channels; tanh bounds the candidate \(\widetilde H\) to −1 through 1. \(\bar w_{t,i,j}\) is the effective write fraction for channel j at location i: spatial multiplier g times learned write fraction w.
\[H_t=H_{t-1}+\bar w_t\odot(\widetilde H_t-H_{t-1})=(1-\bar w_t)\odot H_{t-1}+\bar w_t\odot\widetilde H_t.\]
Symbols and meaning. Each coordinate retains fraction \(1-\bar w\) of the old state and receives fraction \(\bar w\) of the candidate. Example: old state 0.8, candidate −0.2, learned write fraction 0.6, and spatial multiplier 0.5 give effective write 0.3 and new state 0.8 + 0.3(−0.2 − 0.8)=0.5. Normalization shapes the proposed update before it is mixed with the stored H.

The write fraction determines interpolation between old state and proposed new state. The reset fraction controls how much previous memory contributes to constructing the proposal. Because the gate and candidate convolutions have 3 × 3 neighborhoods, nearby locations can interact. The spatial GRU's convolutions couple neighboring locations. Convolutional recurrent models supply a useful mathematical precedent for retaining spatial organization across time. [[cho2014]] [[shi2015]]

With zero initialization, \(\widetilde H\in[-1,1]\) and \(0\le\bar w\le1\) imply by induction that every state coordinate remains in [−1,1]. This is a forward amplitude bound. The full recurrent dynamics also include the dependence of gates, candidates, attention, and future keys on previous state. If those dependencies are held fixed, the direct carry derivative is \(1-\bar w\); the full derivative also contains the derivatives of the gates and candidate.

6.6 Recurrent CLS summary

The CLS GRU has the same normalized write/reset/candidate construction but uses linear layers on \([z_t;c_{t-1}]\) to update the global vector. Spatial selection occurs in \(z_t\), which enters the CLS update with its learned write fraction.

\[w_t^c=\sigma\!\left(\operatorname{LN}_{cw}([W_{cg}[z_t;c_{t-1}]+b_{cg}]_w)\right),\quad r_t^c=\sigma\!\left(\operatorname{LN}_{cr}([W_{cg}[z_t;c_{t-1}]+b_{cg}]_r)\right),\]
Symbols and meaning. The superscript c labels global CLS gates. \(W_{cg},b_{cg}\) transform the concatenated current summary z and previous global memory c into 128 entries. Subscripts w and r outside the brackets take the first and second 64-entry halves. Independent normalization layers produce write and reset gates as in spatial memory, but there is no spatial convolution.
\[\widetilde c_t=\tanh\!\left(\operatorname{LN}_{ch}(W_{ch}[z_t;r_t^c\odot c_{t-1}]+b_{ch})\right),\qquad c_t=c_{t-1}+w_t^c\odot(\widetilde c_t-c_{t-1}).\]
Symbols and meaning. \(W_{ch},b_{ch}\) compute the global candidate \(\widetilde c\). Reset fractions control how much previous c participates in this proposal; write fractions interpolate between old c and the proposal. This is the same retention logic as the spatial equation, applied to a single 64-entry summary. The resulting c is used both for the final response and the next frame’s query.

This state both contributes to the terminal answer and generates the next query. A learned summary can therefore influence what is sampled next. Recurrent neural models provide one account of context-sensitive computation, while studies of working memory show that task information can be distributed across sensory and association systems. [[spatial-mante-2013]] [[miller2001]] [[harrison2009]] [[christophel2017]]

GRUs and LSTMs are distinct. An LSTM separates a cell state and an output-gated hidden state; this implementation has a GRU-style interpolated state and no separate LSTM cell. Persistent activity, dynamic coding, and activity-silent memory provide complementary perspectives on retaining task-relevant information. [[hochreiter1997]] [[lundqvist2016]] [[mongillo2008]]

6.7 Terminal decision and output heads

Concatenate the final CLS vector and selected comparison trace, transform them with a shared 64-unit GELU layer, and apply the head for task \(a\):

\[h^{\rm out}=\operatorname{GELU}(W_o[c_{T-1};m_{T-1}]+b_o),\quad L^{(a)}=W_a h^{\rm out}+b_a,\quad P(y=k\mid X,a)=\operatorname{softmax}(L^{(a)})_k.\]
Symbols and meaning. \(h^{\rm out}\) is the shared 64-entry decision representation. \(W_o,b_o\) map the concatenated 799-entry final state to it. Task index a chooses \(W_a,b_a\), producing answer logits \(L^{(a)}\). Softmax normalizes over the answer classes indexed by k. y denotes the answer class and X the entire movie. The largest output probability determines the model's choice.

The input to the shared layer has 799 channels; the answer head has either two or four outputs. A choice is the largest final logit. No intermediate action terminates the trial, and there is no learned wait/declare policy, reaction-time threshold, or reward critic. The 16 heads add 2,340 parameters in total, compared with 1,950 in the 13-task parent. They allow different answer vocabularies while sharing all preceding computation.

6.8 What learning changes

For an effective batch of \(B=32\) trials from one task and condition, the objective is

\[\mathcal L=\frac1B\sum_{b=1}^B u_b[-\log P_\theta(y_b\mid X_b,a)]+0.05\frac1{B(T-1)N}\sum_{b=1}^{B}\sum_{t=1}^{T-1}\sum_i\omega_{b,t,i}\epsilon_{b,t,i}.\]
Symbols and meaning. B is the number of trials, b indexes trials, T their frame count, and N=100 the patch count. \(y_b\) is the correct terminal answer. The first term is negative log probability of that answer, weighted by \(u_b\): 1 for the original tasks, cue value/3 for VDA. The second term averages reliability-weighted pixel error over trials, noninitial frames, and sites. The learned parameters are collectively \(\theta\); 0.05 fixes the relative pixel-loss coefficient. The weight u here is a trial scalar, distinct from a value vector u earlier.

The summation notation in the second term means all batch examples and times \(t=1,\ldots,T-1\). Reliability weights multiply the error, and the number of terms supplies the averaging denominator. There is no KL loss, VAE decoder, supervised contrastive term, direction label, or flow target in this model. The correspondence bank itself is fixed; its refinement, temperatures, and downstream computations are learned.

Full backpropagation through time is performed in float32. Microbatches of four contribute gradients weighted by their fraction of the effective batch. After accumulation, one global norm is computed over shared parameters and the active task head:

\[\mathbf g=\nabla_\theta\mathcal L,\qquad \mathbf g^{\rm clip}=\mathbf g\min\left(1,\frac{100}{\|\mathbf g\|_2+10^{-6}}\right).\]
Symbols and meaning. \(\mathbf g\) contains derivatives of the loss with respect to all active learned parameters, joined for one global Euclidean norm. Clipping scales the whole vector only if its norm exceeds 100; a zero gradient remains zero. The small additive denominator constant matches the numerical clipping convention. The optimizer applies this operation after gradient accumulation.

No gradient renormalization follows clipping. Adam uses learning rate \(3\times10^{-4}\), default momentum coefficients \((0.9,0.999)\), numerical epsilon \(10^{-8}\), and no weight decay. Its running first and second moments are updated from the clipped gradient, with bias correction before dividing the first moment by the square root of the second. Inactive task heads retain their current parameters and Adam states. [[kingma2015]] [[pascanu2013]]

\[M_n=\beta_1M_{n-1}+(1-\beta_1)\mathbf g_n^{\rm clip},\quad U_n=\beta_2U_{n-1}+(1-\beta_2)(\mathbf g_n^{\rm clip})^2,\quad \theta_n=\theta_{n-1}-\eta\frac{M_n/(1-\beta_1^n)}{\sqrt{U_n/(1-\beta_2^n)}+10^{-8}}.\]
Symbols and meaning. n counts optimizer updates for the parameter in question. M and U are running first and squared-gradient moments, distinct from model memory m. \(\beta_1=0.9\), \(\beta_2=0.999\), and \(\eta=0.0003\). Powers \(\beta_1^n,\beta_2^n\) correct zero-initialized moments. Squaring, square roots, and division act coordinatewise. The optimizer retains these variables between training updates. Evaluation uses the learned parameters and the trial's recurrent states.

One shuffled cycle supplies one update to each of 16 tasks in the VDA continuation (13 in the original suite); conditions cycle separately within a task. Each update draws fresh trials. Each task receives equal update opportunities; frame counts, computation, and gradient contributions depend on its trials. Long movies require more recurrent computation, and a task with twelve conditions gets fewer updates per condition than a task with one. Task-level retention and transfer measurements track how joint training affects the shared representations.

6.9 A precise parameter inventory

The 64-channel spatial GRU contains most of the learned parameters. The fixed correlation bank contributes zero learned parameters. The parameter table separates structural priors from learned capacity: the large 735-channel comparison vector is mostly a fixed representation, whereas its shared terminal projection is learned.
