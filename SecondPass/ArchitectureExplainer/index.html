Attention, memory and decision.

Follow the newer architecture from pixels to beliefs. Pause anytime, or choose a chapter. Narration and on-screen captions explain each component as it appears.

Names and sizes, at a glance
  • Spatial recurrent memory: 100 sites × 64 channels = 6,400 stored numbers.
  • CLS recurrent memory: one evolving 64-number state, updated from selected values.
  • Learned CLS token: 64 trainable parameters; the same vector is used throughout a trial.
  • Comparison memory: 735 stored numbers, updated from attention-pooled temporal comparisons.
  • Query: one 64-number vector combining previous CLS memory and, in the newer architecture, a projection of previous spatial memory.
  • Beliefs: task output probabilities produced by a shared readout and task-specific head.
Training objectives and implementation details

The terminal classification loss is cross-entropy. VDA examples multiply it by their assigned value divided by 3. An auxiliary normalized pixel-transport error enters the objective with weight 0.05. Adam updates learned parameters after gradient-norm clipping at 100.

Spatial gates use 3 × 3 convolutions. Gate and candidate computations receive LayerNorm before sigmoid/tanh. Attention modulates the write through α / (α + 0.01). Comparison memory uses z ← 0.8z + 0.2 selected comparison. Its reference window spans t−15 through t−8; its recent window spans t−3 through t, with a four-frame gap. Early windows use available history and reliability weighting.

This animation focuses on the three principal memory representations. Additional temporal state includes the motion-population trace and previous flow; earlier pixel frames supply the lagged comparisons. The original model lacks the newer direct spatial-memory-to-query projection.

The activity patterns and belief bars are teaching illustrations. Connections and dimensions were checked against the local implementation. Voice is synthesized locally; no training was started.
