## Actual architecture and equations
Input X∈R[B,T,3,100,100]. Center X−0.5. For each t, concatenate neighboring full RGB frames [X(t−1),X(t),X(t+1)] (zeros outside sequence) to9channels. Learn a stride-one3×3 Conv2d9→8 plus GELU, equivalent to a3×3×3 spatiotemporal convolution3→8. **This is learned local motion filtering, not optical flow, fixed image differences, ROI selection, a direction estimator or a supplied comparison rule.** Fine subpixel raster values enter the learned filter before any spatial reduction.

Learned spatial aggregation Conv2d8→24,kernel5,stride5 gives20×20; GELU; Conv2d24→48,kernel2,stride2 gives10×10. No global average of pixels. This is still a lossy learned bottleneck; preserving native input does not guarantee preserving useful information.

Add independent learned spatial positions[100,48] and temporal positions[45,48]. Two axial blocks each perform temporal self-attention on allT tokens independently at each of100 sites, then spatial self-attention on all100 sites independently at each frame. Width48,4 heads (12dimensions/head), pre-LayerNorm, residual linear projection, FFN48→96→48 GELU. For each attention: A=softmax(QKᵀ/√12), z←z+Wo(AV); z←z+W2 GELU(W1 LN(z)). No dropout. No causal mask is needed for end-of-trial reporting.

After both full-history blocks, a learned scalar48→1 per token creates temporal softmax weights w(t,s); h(s)=Σt w(t,s)z(t,s). Flatten100×48→4800, LayerNorm4800, Linear4800→128, GELU, Linear128→2. Final ordinary binary cross-entropy only. Spatial/temporal comparisons are learned jointly from label loss; earlier frames remain directly accessible through attention rather than carried solely in a recurrent terminal state. This is a computational diagnostic, not a biological circuit claim.
