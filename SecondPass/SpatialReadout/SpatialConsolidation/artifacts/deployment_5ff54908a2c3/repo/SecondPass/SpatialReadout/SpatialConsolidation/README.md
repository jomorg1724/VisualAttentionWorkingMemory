## Exact computation

Reuse the original CNN, three recurrent KDA encoder scales, spatial input projection and final ConvGRU. Compute all recurrent frames with full BPTT exactly as before. After the LAST ConvGRU state only:

1. `B,64,7,7 -> B,49,64`, token `i = row*7 + column` (row-major spatial flatten).
2. Add fixed FP32 2D sinusoidal position buffer of shape `1,49,64` ONCE. For `j=0..15`, `omega_j=10000**(-j/16)`, integer row/column `0..6`; channel concatenation `[sin(row*omega), cos(row*omega), sin(column*omega), cos(column*omega)]`. No learned positions, coordinate normalization, temporal positions or rotary embedding.
3. One pre-normalized encoder block: `x += Wout SDPA(Q,K,V)` with QKV from RMSNorm(x); four heads, dimension16/head. Full bidirectional spatial self-attention, `attn_mask=None`, `is_causal=False`, `dropout_p=0.0`, default scale `1/sqrt(16)`. QKV/output projections bias-free.
4. `z=RMSNorm(x); x += Wdown(silu(Wgate z) * Wup z)`; SwiGLU hidden width176, all FFN projections bias-free.
5. Final RMSNorm, transpose/reshape back to `B,64,7,7`, then the **unchanged** flatten3136 → Linear256 → ReLU → existing task head.

Each RMSNorm computes `x * rsqrt(mean(x**2, dim=-1, keepdim=True) + 1e-6) * weight`; learned 64-channel scale initialized to ones, no bias/mean subtraction. All linear weights retain ordinary PyTorch default initialization. No gate-zero initialization, frozen module, inherited tensor, CLS token, pooling, decoder convolution, recurrent feedback, cache, auxiliary labels or oracle task-phase input.

Measured CPU construction: **1,433,396 learned parameters**, versus base 1,383,028: **50,368 added**, 76 learned tensors in the complete 13-head model. Position buffer is fixed, not a learned tensor.

These are defensible modern conventions, not a claim of universally optimal normalization/position/FFN design. Bounded source check:
- PyTorch SDPA API: https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.scaled_dot_product_attention.html (explicit zero dropout is required even in evaluation; default inverse-square-root scaling; no causal mask here).
- Zhang & Sennrich, *Root Mean Square Layer Normalization*: https://arxiv.org/abs/1910.07467 .
- Shazeer, *GLU Variants Improve Transformer*: https://arxiv.org/abs/2002.05202 .
