Reproducibility and source map
Reader question: how can a reader check the computation without running a trained model? The
editable source, constructor audit, complete SHA-256 manifest, and PDF veriﬁcation receipts are colocated in this repository
directory:
SecondPass/SpatialReadout/ArchitecturePaper/
Counts were obtained with PyTorch 2.8.0 on CPU with intra/inter-op threads limited to two. No checkpoint was loaded;
no model forward/backward, dataset download, optimizer update, or accelerator operation was used. Shapes in Tables 1–2
follow the actual constructor attributes and convolution output formula. Biases and GroupNorm aﬃne tensors are included;
temporary inherited modules deleted by the subclass are excluded.

Teaching checks. The original ten-page version is preserved in versions/v1_10page/. The revised transport notation
replaces the formerly overloaded projection/propagator letter. toy_verification.json records exact rational decay, predic-
tion, residual, correction, read, transition, and three-step unrolling checks. These are teaching calculations, not new model
results.
Build. Run python3 build.py here (Tectonic is conﬁgurable via TECTONIC). Run the CPU interpreter on verify_counts.py
to refresh counts; run python3 verify_pdf.py for text, bounds, font, page, and rendering checks. The original model/training
sources are not modiﬁed. The PDF receipt distinguishes automated checks from visual inspection. The local source snapshot,
rather than an asserted latest checkpoint score, deﬁnes the report’s freshness.
