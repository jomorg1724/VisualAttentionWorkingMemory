The cue is part of the rendered image. Its location or meaning must aﬀect the shared trunk through learned image
processing. The externally supplied task name takes a separate route: it selects the output vocabulary, without
telling the trunk the target or answer. There is no learned task-ID inference module.[S1,S7]
Takeaway. There are four recurrent pathways, not a single global attention map. The ﬁnal task-known classiﬁer
is distinct from interpreting an endogenous visual cue.
