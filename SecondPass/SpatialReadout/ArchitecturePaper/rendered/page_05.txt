One KDA update: prepare, decay, correct, read
Reader question: how can a matrix act as an associative memory? Fix one scale s, site p, and head j,
and suppress these indices. Think of S ∈R8×16 as a table that maps a key direction to a predicted value via STk.
This is an analogy to an addressable notebook, not a claim that a key is an object identity or a value is an angle.
The channels are learned features; their semantic content is not established by the architecture.
